# Delivered capabilities and boundaries

Veyra Studio 0.1.0 is a working browser editor. It is not a complete replacement for DaVinci Resolve and has not been qualified for production finishing.

| Area | Implemented | Remaining boundary |
| --- | --- | --- |
| Workspaces | Media, Cut, Edit, Fusion, Color, Audio, Deliver; common project, timeline and selection; dark and light appearances | Cut is an alternate presentation of the same editor, not an independent source-tape or dual-timeline implementation. No Photo page or native multi-window docking. |
| Media | Browser video/audio/image import, source preview, image/video thumbnails, waveform extraction, search, category bins, in/out, relinking, durable uploads | Browser-decoder-dependent codecs; 100 MB per hosted upload; no RAW, BRAW, ProRes/DNx mastering, camera metadata pipeline, proxy generation, background transcode or huge-media streaming qualification |
| Timeline | Multiple tracks, drag/move/trim, split, delete, ripple delete, duplicate, snapping, markers, locks, audio solo/mute, zoom and history | No multicam, compound/nested sequences, slip/slide/roll trim suite, magnetic track behavior, full ripple conflict semantics or native project import |
| Transforms/titles | Position, scale, rotation, opacity, text, font, size, color, linear keyframes | No rich typography engine, subtitle editor, 3D text, Bezier keyframe editor or arbitrary time-remap curves |
| Picture | Canvas composition, native WebGPU/WGSL per-clip grading, CPU fallback, still-animation and decoded video playback | GPU pipeline includes canvas transfers; not zero-copy. Physical-GPU throughput and device-loss recovery require browser qualification. CPU grading at high resolution can be slow. |
| Color | Exposure, contrast, saturation, temperature/tint, scalar lift/gamma/gain, vignette, presets, live RGB histogram | Wheels are scalar controls, not full chroma-vector grading. No calibrated color management, ACES/OCIO, HDR mastering, LUT import, secondary keys/windows/tracking, noise reduction or certified scopes |
| Fusion | Editable serial chain, Color/Blur/Monochrome nodes, enable/bypass, removal, graph cycle validation | No arbitrary branched composition, node dragging/wiring, masks, rotoscoping, tracking, keying, 3D scenes, particles or deep compositing. Color-node parameters are combined into the grade; this is a limited processing graph. |
| Audio | Web Audio gain/pan/fades, track gain/mute/solo, low/high shelf EQ, master gain, RMS display, mixed export audio | Meter bars derive from a common analyser and are not calibrated per-channel meters. No LUFS/true peak, time-stretch algorithm, plugins, ADR, immersive formats, recording or device qualification. Reverse shuttle is picture-only. |
| Delivery | Real-time MediaRecorder WebM or MP4 where supported, resolution/frame-rate/bitrate controls, progress/cancel/download, PNG frame, basic EDL, SRT and project JSON | One active render job. No deterministic offline render, printer/monitor-identical finishing, broadcast master presets, render farm, arbitrary codecs or archival qualification. Fast motion and slow hardware can drop frames. |
| Storage | D1 structured projects, source media in R2, membership checks, revision checks, local SQLite/files alternative | Project JSON does not embed media. Local mode uses one trusted local user. No archival version browser, offline sync queue, object-store cleanup/retention, enterprise backup or quota administration. |
| Collaboration | Shared project codes, member list/presence, timestamped comments, four-second synchronization, disjoint-object merge, explicit conflicts, owner removal | Not WebSocket/CRDT; no character-level merge, edit locking, review drawings, enterprise roles, audit/compliance/SSO administration or scaled coauthoring qualification. Remote changes clear snapshot undo history. |
| Modularity | Five ES-module packages; generated standalone npm tarballs; local app/server in one repository | APIs are new, not compatible with a proprietary desktop API. Controls package expects a documented DOM contract. No npm publication, native application installers, framework wrappers or stable 1.0 API promise. |

The reference was the official product/workspace documentation at https://www.blackmagicdesign.com/products/davinciresolve and its `/edit`, `/color`, `/fusion`, `/fairlight`, and `/media` pages. The site described Resolve 21 at implementation time. The implementation uses its workflow as a reference while retaining an independent name and codebase.

The sample uses one generated coastal photograph with different framing and grading. Its soundtrack is a simple original synthesized pad. Imported moving footage uses the browser's actual media decoder. Import and export compatibility must be assessed against representative production assets.
